# E3D 可加载建模标准

## 建模前置条件

模型宏默认在一个已存在、可写的 `ZONE` 下运行。用户应在 Model Explorer 中选中该 ZONE，使其成为 CE，再执行：

```text
$M/<macro-path>
```

不要在宏内臆测 SITE 或 ZONE 名称。ZONE 必须归属于 SITE；新建 SITE / ZONE 需要项目命名规则和用户确认。

## 标准几何层级

使用 E3D Design 的原生命令，而不是对象属性伪代码：

```text
NEW EQUI /MODEL_CASE_001
DESC 'Model case'
POS E 0 N 0 U 0
NEW CYLI
DIAM 41
HEIG 8

NEW EQUI /MODEL_LINK_001
POS E 0 N 34 U 2
NEW BOX
XLEN 20
YLEN 18
ZLEN 3
```

所有数值单位为 mm。每个设备仅承载一个可独立定位的可视部件时，检查、定位和删除更可靠。

## 高拟真空间精度

- 在宏之外保留参数表，列出来源规格、坐标系、派生坐标与净空计算。
- 设定原点和正方向，例如腕表以 `(0, 0, 0)` 为中壳/底盖接合平面中心，`+N` 为 12 点钟、`+E` 为表冠、`+U` 为镜面。
- CYLI 的定位点按底面中心计算；BOX 的定位点按几何中心计算。轴向叠层必须逐层列出 `U 起点`、`U 终点` 和最小净空。
- 指针等定向长方体：先选定局部 Y 方向，再以目标半长沿该方向偏移 BOX 中心，使其内端落在旋转中心。
- 不能仅依靠视觉近似：表耳跨度、节距、同轴直径、径向净空和防碰撞间隙必须由参数计算得出。

## 命名与复跑

- 使用一个物体前缀和版本后缀，例如 `WATCH_DV_CASE_001`。
- 同一数据库内 E3D 名称必须唯一。
- 重跑宏前，删除已有同前缀元素，或把后缀递增为 `_002`。

## 静态验收

1. 每个 `NEW EQUI` 名称唯一。
2. 每个 `NEW CYLI` 都有 `DIAM` 和 `HEIG`。
3. 每个 `NEW BOX` 都有 `XLEN`、`YLEN` 和 `ZLEN`。
4. 默认模型宏不含 `NEW SITE` 或 `NEW ZONE`。
5. 宏开头必须写明模型单位、CE 前置条件和数据基线。
