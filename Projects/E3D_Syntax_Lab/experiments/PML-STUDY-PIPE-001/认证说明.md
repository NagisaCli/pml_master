# PIPE 原生语法第一轮 E3D 认证说明

## 导入前

这些宏会建立独立的测试 SITE，不会写入现有设备的 EQUI：

- `/CODEX-PIPE-LAB01`
- `/CODEX-PIPE-LAB02`
- `/CODEX-PIPE-LAB03`
- `/CODEX-PIPE-LAB04`
- `/CODEX-PIPE-LAB05`

请在 E3D Design 中选择 `WORLD`，然后使用：

```
$M <候选宏的完整路径>
```

每个宏只运行一次。重复运行前需要先在 E3D 中删除或重命名对应的
`/CODEX-PIPE-LABxx`，否则重名元素会干扰判断。

## 建议执行顺序

### 1. `01_pipe_core.pml`

目标：验证基本层级、自动直管和常用管件。

预测结果：

1. `/CODEX-P01-T01-STRAIGHT`
   - 一根 DN100 水平直管；
   - 从 `E 0 N 0 U 0` 到 `E 4000 N 0 U 0`；
   - 如果出现，说明没有独立 TUBE 元素时，BRANCH 头尾之间可以自动形成管段。
2. `/CODEX-P01-T02-ELBOW`
   - DN100 管道先向上 2000 mm，再通过弯头转向 West 4000 mm；
   - 弯头应位于 `E 0 N 5000 U 2000`。
3. `/CODEX-P01-T03-VALVE`
   - DN20 的 `GASKET → FLANGE → VALVE` 组合；
   - 沿 South 方向布置。
4. `/CODEX-P01-T04-REDUCER`
   - 一根垂直向下的管段；
   - 中间由 DN100 过渡到 DN80。

如果报告 `/A3B/...` 未定义，请保留完整错误。这表示接收项目的目录不同，
不一定表示 PIPE 语法错误。

### 2. `02_pose_pos_then_ori.pml`

目标：验证原生导出的管件顺序 `POS → ORI`。

预测：

- 宏正常载入；
- DN100 管道从原点向上 2000 mm，然后转向 West 4000 mm；
- 弯头中心在 `E 0 N 0 U 2000`；
- 管段与弯头连续，没有漂移。

### 3. `03_pose_ori_then_pos.pml`

目标：只把 ELBOW 改为 `ORI → POS`，其余条件与 02 相同。

重点比较：

- 是否直接报错；
- 弯头是否仍位于 `E 0 N 0 U 2000`；
- 管段是否断开、漂移或方向错误；
- 最终形状是否与 02 完全相同。

判断：

- 如果 03 错误或几何不同：管道组件顺序具有语义，暂定必须
  `POS → ORI`。
- 如果 02、03 完全一致：原生顺序可能只是导出器的规范化格式，不是执行约束。

### 4. `04_tee_branch_refs.pml`

目标：验证 TEE 和第二 BRANCH 的双向连接。

预测：

- B1 为带一个弯头和一个 TEE 的主管；
- B2 从 North 方向接入 TEE 支口；
- B2 与 TEE 之间没有缝隙或重复管段。

请分别查询：

```
TEE 1 of BRANCH /CODEX-P04-TEE/B1
Q CREF

/CODEX-P04-TEE/B2
Q TREF
```

预期：

- TEE 的 `CREF` 指向 `/CODEX-P04-TEE/B2 TAIL`；
- B2 的 `TREF` 指向 `TEE 1 of BRANCH /CODEX-P04-TEE/B1`。

### 5. `05_slope_1in100.pml`

目标：验证坡度引用和方向表达。

预测：

- 一根 DN100 直管，水平投影长度 10000 mm；
- 从 `U 100` 降到 `U 0`，即 1:100；
- PIPE 和 BRANCH 的 `SLOREF` 都为 `/1in100`。

请在 PIPE 和 BRANCH 上分别执行 `Q SLOREF`。

## 第二轮补充实验

第一轮已经确认绿色虚线代表几何上未完成的路由，不是实体管道。

### 6. `06_elbow_arrive2_leave1.pml`

仅在02号宏基础上恢复原生弯头的：

```
ARRI 2
LEAV 1
```

预测：两段绿色虚线都变为实体管道，并与弯头连续。

请在 ELBOW 上查询：

```
Q ARRIVE
Q LEAVE
Q ADIR
Q LDIR
```

### 7. `07_reducer_vertical_native_axes.pml`

仅把 REDUCER 的方向改成多个原生垂直异径管采用的：

```
ORI Y is N and Z is E
```

预测：异径管由北南方向改为竖直方向，DN100和DN80管段在上下两侧形成实体。

请在 REDUCER 上查询：

```
Q ADIR
Q LDIR
Q ABORE
Q LBORE
```
