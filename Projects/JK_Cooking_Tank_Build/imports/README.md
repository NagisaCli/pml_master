# Native E3D imports

Store future user-supplied native E3D exports here **unchanged**. Use a dated
filename, for example:

```text
2026-08-15_JK_Cooking_Tank_Build_native.pml
```

Never edit the imported evidence file directly. Compare it against the latest
accepted baseline with `python -m wsb.pml_compare`, copy it to a working file,
and preserve every out-of-scope manual difference.
