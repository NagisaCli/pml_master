5. E3D PRIMITIVE DESCRIPTION STRING RULE
--------------------------------------------------

Some equipment heights are provided as primitive definition strings.

Example:

FTTD:CY:D3876 H2508;
CONE:DT:3876 DD:7300 H2944;
CY:D:7300 H:8753;
CONE:DT:7300 DD:555 H:5898;


This format is an AVEVA E3D Equipment Primitive geometry definition.

Interpretation rules:

- The primitives are arranged from TOP to BOTTOM.
- Do NOT reverse the order.
- Do NOT reinterpret the orientation.

Syntax:

CY:
Cylinder

Parameters:
D = diameter
H = height


CONE:
Cone / conical transition

Parameters:
DT = top diameter
DB or DD = bottom diameter
H = height


Example:

CONE:DT:7300 DD:555 H:5898

means:

Top diameter = 7300 mm
Bottom diameter = 555 mm
Height = 5898 mm


All dimensions are in millimeters.

Primitive elements automatically connect end-to-end.

Use this string directly as the authoritative equipment outer profile definition.
